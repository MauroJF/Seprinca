# 🛡️ SEPRINCA C.A. — Sitio Web Corporativo

Repositorio oficial de la página web corporativa de **SEPRINCA C.A.** (Servicios Profesionales e Integrales de Vigilancia Privada). 

El sitio está diseñado con un enfoque **Mobile-First**, priorizando rendimiento, accesibilidad (UI/UX) y un posicionamiento orgánico técnico optimizado para motores de búsqueda (SEO).

🌐 **Sitio en vivo:** [https://seprinca.net/](https://seprinca.net/)

---

## 📌 Características Principales

* **Diseño Limpio y Accesible:** Paleta de colores corporativa basada en morado (`#3a1c4a`) sobre fondo claro (`#ffffff`), garantizando un alto contraste y legibilidad.
* **Llamados a la Acción (CTA) Dinámicos:** Botón principal de conversión con animación `@keyframes pulse-glow` para maximizar la tasa de respuesta de clientes potenciales.
* **SEO Técnico e Indexación:**
  * Estructura semántica HTML5.
  * Archivo `sitemap.xml` para indexación directa en Google Search Console.
  * Etiquetas Meta actualizadas para optimización de marca.
* **Carga Ultrarrápida:** Arquitectura ligera en HTML/CSS sin dependencias pesadas ni frameworks innecesarios.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica.
* **CSS3:** Estilos personalizados, variables CSS (`var(--morado)`), Flexbox y animaciones keyframe.
* **GitHub Pages:** Alojamiento y despliegue continuo (CD/CI integrado).
* **Google Search Console:** Monitoreo de rastreo e indexación.
